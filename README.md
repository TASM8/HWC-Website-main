# 🌈 Handle With Care

Welcome to the **Handle With Care** website!

Handle With Care was created by Taylor Signs-McMurtry and Jenna Fountain in 2026. The goal of this website is to provide a welcoming and supportive space for parents, families, faith leaders, allies, and anyone who wants to learn more about the LGBTQIA+ community.

## 💛 Our Mission

Handle With Care exists to equip parents, families, and allies with compassionate education, practical tools, and supportive community so they can confidently affirm and uplift the LGBTQIA+ people in their lives.

We believe that kindness, education, understanding, and community can help create safer and more supportive spaces for everyone.

## 📚 Website Pages

The website currently contains three main pages:

- **Home** – Introduces Handle With Care and shares our mission statement and contact information.
- **About** – Introduces the people behind Handle With Care and explains how the program came to be.
- **Resources** – Provides information about other organizations that support the community and share similar goals.

## 🤝 Organizations We Support

The Resources page highlights organizations that are important to the Handle With Care mission, including:

- Culture for Change
- Queer Cupboard
- Southern Idaho Pride

These organizations provide community support, education, resources, and opportunities to connect with others.

## 💻 Technologies Used

This website was created using:

- HTML5
- CSS3

The website uses a separate CSS stylesheet to keep the design consistent across all pages.

## 🎨 Design

The website was designed to feel:

- Welcoming
- Warm
- Supportive
- Fun
- Easy to navigate

The color palette uses warm burgundy, gold, cream, and other soft colors to create a comfortable and inviting atmosphere.

The website also includes responsive design so that the pages can be viewed on both computers and mobile devices.
